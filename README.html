OncoPath

Specialized Oncological and Pathological Research Tools for jamovi and R

Overview

OncoPath is a specialized jamovi module and R package designed specifically for oncological clinical trials and pathology research. As the oncology and pathology follow-up engine of the ClinicoPath ecosystem, it provides specialized tools for patient timeline tracking, tumor burden response assessment, diagnostic test meta-analysis, immunohistochemistry (IHC) marker heterogeneity, and pathology diagnostic agreement.

🎯 Key Features & Analysis Suite (5 Analyses)

OncoPath provides 5 specialized analyses under the OncoPath menu in jamovi:

Analysis Function Menu Subgroup Key Clinical & Pathological Features
Swimmer Plot swimmerplot Patient Follow-Up Plots Comprehensive patient timeline visualization using enhanced ggswim; displays disease duration, start/end dates, clinical milestones, discrete events, adverse event flags, and response durations for clinical trial reporting.
Treatment Response (Waterfall & Spider) waterfall Patient Follow-Up Plots Patient-level tumor burden analysis; generates publication-ready waterfall and longitudinal spider plots; measures progression against nadir; categorizes response (CR, PR, SD, PD) using adapted RECIST v1.1 thresholds; reports ORR, DCR, exact binomial CIs, and person-time metrics.
Diagnostic Test Meta-Analysis diagnosticmeta Meta-Analysis Comprehensive meta-analysis of diagnostic accuracy studies in pathology and AI/ML algorithm validation; implements bivariate random-effects modeling (Reitsma method), proportional-hazards SROC (Holling model), meta-regression for heterogeneity, and publication-ready forest/SROC plots.
IHC Heterogeneity Analysis ihcheterogeneity IHC Analysis Quantitative statistical analysis of immunohistochemical biomarker heterogeneity; evaluates intratumoral expression variance, multi-marker profiles, spatial distribution indices, and clinical-pathological correlates.
Pathology Agreement pathagreement Agreement Multi-rater agreement analysis tailored to histopathological scoring; computes Cohen’s Kappa, Fleiss’ Kappa, Krippendorff’s alpha, diagnostic consensus determinations (majority, super-majority), and rater concordance matrices.

Detailed Analysis Capabilities

🏊‍♂️ Swimmer Plot (swimmerplot)

  • Patient Timeline Visualization: Professional swimmer charts showing therapy courses, treatment switching, and ongoing responses.
  • Multidimensional Event Overlays: Plot milestones (e.g. partial response, disease progression, toxicity) and continuous bars on the same axis.
  • Trial Reporting Ready: Formatted according to oncology trial presentation standards.

🌊 Treatment Response (waterfall)

  • Tumor Burden Visualization: Waterfall plots of best percentage change from baseline and spider plots showing burden trajectories across visits.
  • Adapted RECIST v1.1 Thresholds: Response classification tailored for patient-level burden when single summary measurements or calculated percent changes are recorded.
  • Nadir-Based Progression: Progression calculated relative to the smallest recorded tumor burden (nadir).
  • Exact Clinical Metrics: Objective Response Rate (ORR) and Disease Control Rate (DCR) with exact Clopper-Pearson binomial confidence intervals.

📊 Diagnostic Test Meta-Analysis (diagnosticmeta)

  • Bivariate & SROC Modeling: Bivariate random-effects synthesis preserving the negative correlation between sensitivity and specificity.
  • AI Algorithm Validation: Evaluate performance metrics of digital pathology and artificial intelligence diagnostic models across validation cohorts.
  • Heterogeneity & Meta-Regression: Investigate study-level covariates explaining differences in diagnostic accuracy.

🔬 IHC Heterogeneity Analysis (ihcheterogeneity)

  • Biomarker Variance: Assess intra-tumoral and inter-observer variability in immunohistochemical staining.
  • Quantitative & Semiquantitative: Supports continuous H-scores, percentage positive cells, and ordinal intensity tiers.

🤝 Pathology Interrater Reliability (pathagreement)

  • Diagnostic Concordance: Evaluate consensus and discordance patterns across multiple evaluating pathologists.
  • Diagnostic Triage: Automated calculation of agreement levels for borderline and equivocal pathology categories.

🚀 Installation

In jamovi (Recommended)

  1. Open jamovi (>= 2.6).
  2. Click Modules (top right) → jamovi library.
  3. Search for OncoPath.
  4. Click Install.

As an R Package

# Install development version from GitHub
remotes::install_github("sbalci/OncoPath")

💡 Quick Start (R Interface)

library(OncoPath)

# 1. Swimmer Plot for patient timelines
data("swimmerplot_sample", package = "OncoPath")
swim_res <- OncoPath::swimmerplot(
  data = swimmerplot_sample,
  patientID = "patient_id",
  startTime = "start_time",
  endTime = "end_time",
  responseVar = "response"
)

# 2. Treatment Response Waterfall Plot
data("waterfall_percentage_basic", package = "OncoPath")
wf_res <- OncoPath::waterfall(
  data = waterfall_percentage_basic,
  patientID = "patient_id",
  responseVar = "change_from_baseline"
)

# 3. Diagnostic Meta-Analysis for Pathology Studies
data("diagnostic_studies", package = "OncoPath")
meta_res <- OncoPath::diagnosticmeta(
  data = diagnostic_studies,
  tp = "TP",
  fp = "FP",
  fn = "FN",
  tn = "TN",
  study = "study_name"
)

📚 Example Datasets

OncoPath includes authentic example datasets available directly in the jamovi Data Library (Open → Data Library → OncoPath):

  • swimmerplot_sample.omv: Patient timelines, milestones, and responses.
  • waterfall_percentage_basic.omv: Best percent change for single-visit waterfall analysis.
  • waterfall_raw_longitudinal.omv: Multi-visit raw tumor burden data for waterfall and spider plots.
  • diagnostic_studies.omv: Diagnostic accuracy study cohorts for meta-analysis.
  • ihcheterogeneity_test.omv: Multi-region IHC staining scores for heterogeneity testing.
