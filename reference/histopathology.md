# Histopathology Sample Dataset

A general-purpose synthetic clinicopathological data frame (250 cases,
38 variables) from the ClinicoPath project. No OncoPath analysis uses
it; it is included as a frame for exploring jamovi. The `Name` column
holds invented first names, several logical columns are coded with
Turkish TRUE/FALSE strings, and the column "Golden Standart" keeps its
original spelling.

## Usage

``` r
histopathology
```

## Format

A data frame with 250 rows and 38 variables.

## Source

Simulated example data from the ClinicoPath project.
