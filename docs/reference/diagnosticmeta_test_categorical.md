# diagnosticmeta_test_categorical: example dataset for the OncoPath module

Example dataset distributed with the OncoPath jamovi module for
demonstration and testing.

## Usage

``` r
diagnosticmeta_test_categorical
```

## Format

A data frame with 20 rows and 8 variables:

- study:

  character variable

- true_positives:

  numeric variable

- false_positives:

  numeric variable

- false_negatives:

  numeric variable

- true_negatives:

  numeric variable

- year:

  integer variable

- quality_score:

  numeric variable

- imaging_modality:

  character variable
