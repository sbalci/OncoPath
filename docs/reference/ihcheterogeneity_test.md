# ihcheterogeneity_test: example dataset for the OncoPath module

Example dataset distributed with the OncoPath jamovi module for
demonstration and testing.

## Usage

``` r
ihcheterogeneity_test
```

## Format

A data frame with 50 rows and 7 variables:

- case_id:

  character variable

- wholesection:

  numeric variable

- biopsy1:

  numeric variable

- biopsy2:

  numeric variable

- biopsy3:

  numeric variable

- biopsy4:

  numeric variable

- spatial_id:

  character variable
