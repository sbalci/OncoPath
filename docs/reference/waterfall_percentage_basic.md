# Waterfall Plot Percentage Basic Dataset

Twenty synthetic patients for the `waterfall` analysis with percentage
input: one row per patient.

## Usage

``` r
waterfall_percentage_basic
```

## Format

A data frame with 20 rows and 3 variables:

- PatientID:

  Patient identifier, PT01 to PT20

- Response:

  Best percent change in tumour burden from baseline (negative =
  shrinkage; -100 = complete disappearance)

- Treatment:

  Treatment arm: Drug A or Drug B (10 patients each)

## Source

Synthetic data generated for the ClinicoPath project.
